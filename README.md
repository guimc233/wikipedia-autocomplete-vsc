# Wikipedia Link Picker

受 [cubk](https://cubk.cn/articles) 的[博客](https://zh.wikipedia.org/wiki/%E5%8D%9A%E5%AE%A2)文章启发, 花费了[3分钟](https://zh.wikipedia.org/wiki/%E8%B5%9B%E9%9B%B7%E4%B8%89%E5%88%86%E9%92%9F)的时间, 使用 [Codex](https://zh.wikipedia.org/wiki/Codex) 进行[氛围编程](https://zh.wikipedia.org/wiki/%E6%B0%9B%E5%9B%B4%E7%BC%96%E7%A8%8B)完成了该[项目](https://zh.wikipedia.org/wiki/%E9%A1%B9%E7%9B%AE)

该[项目](https://zh.wikipedia.org/wiki/%E9%A1%B9%E7%9B%AE)没有经过任何[人工](https://zh.wikipedia.org/wiki/%E4%BA%BA%E5%B7%A5)审查, 请谨慎使用

若对本[项目](https://zh.wikipedia.org/wiki/%E9%A1%B9%E7%9B%AE)有任何建议, 请新建一个Issue, 或是自行完成后开启一个Pull Request.

## Install

打开该[项目](https://zh.wikipedia.org/wiki/%E9%A1%B9%E7%9B%AE)的[Release](https://github.com/guimc233/wikipedia-autocomplete-vsc), 下载vsix[档案](https://zh.wikipedia.org/wiki/%E6%A1%A3%E6%A1%88), 将其安装到你的[VSCode](https://zh.wikipedia.org/wiki/VSCode), 在编辑[Markdown](https://zh.wikipedia.org/wiki/Markdown)文件时, 选中[文本](https://zh.wikipedia.org/wiki/%E6%96%87%E6%9C%AC), 按下[Ctrl](https://zh.wikipedia.org/wiki/Ctrl%E9%94%AE)+[Alt](https://zh.wikipedia.org/wiki/%E8%BD%AC%E6%8D%A2%E9%94%AE)+W即可[体验](https://zh.wikipedia.org/wiki/%E4%BD%93%E9%AA%8C)
